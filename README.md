## 🚀 Mis proyectos

### 🎟️ Event Pass

Sistema de gestión de eventos artísticos, desarrollado para facilitar la organización y administración de eventos.

**Características:**
- Gestión de información de eventos.
- Interfaz web interactiva.
- Aplicación de patrones de diseño de software.

### 🚌 MoviPass

Sistema web para la gestión de cooperativas de transporte y buses, desarrollado de manera colaborativa.

**Características:**
- Administración de cooperativas.
- Gestión de buses.
- Diseño de interfaces web.
- Integración con base de datos.

**Tecnologías:** HTML, CSS, JavaScript y Supabase.

📌 **Estado:** En desarrollo.
